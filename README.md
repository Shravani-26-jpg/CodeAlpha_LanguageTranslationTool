## 📌 Project Overview
This project is a web-based **Language Translation Tool** built as part of the CodeAlpha Artificial Intelligence Internship.  
The tool enables users to translate text between multiple languages using a simple and intuitive interface.

The backend communicates with the **MyMemory Translation API** to fetch translated text in real time.

---

## 🚀 Features
- Translate text between different languages  
- Clean and user-friendly interface  
- Real-time translation  
- Supports long paragraphs  
- Text-to-speech functionality  
- Copy translated text with one click  
- Error handling for invalid inputs  
- Fully responsive design
